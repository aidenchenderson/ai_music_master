- AI Music Master -

Overview:

Music Master helps new guitarists learn core fundamentals and gives context about influential genres, using AI-powered, real-time audio analysis.

Project Mission:

Our custom-trained CNN follows a ResNet architecture to extract complex audio patterns over a wide range of descriptors, capturing rhythm, timbre, brightness, and more! With a portable design, guitarists can continue their learning journey no matter where they are.

Features:

  • Audio Engine, Feature Extractor, and Audio Processor
  • Terminal User Interface (TUI) with Recording Sessions
  • Genre Classification CNN
  • Summarization LLM API
